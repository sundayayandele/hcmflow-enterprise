# Capability map

Scope includes every HCMFlow solution area, delivered in phases. “Planned” is not implemented. Phase ordering follows the user's current payroll-first direction rather than the older HR-first reference draft.

| Capability | Domain owner | First useful increment | Phase / status |
|---|---|---|---|
| Core HR | Workforce | Employee creation, source provenance, validated imports | 0 implemented; lifecycle history in 1 |
| Payroll | Payroll | Synthetic gross-to-net, calendars/elements, snapshots and checker review | 0 simulation; validated Nigeria engine in 1 |
| Employee self-service | Identity + employee services | Own profile, profile change request, own payslip access | 1 planned; own-record backend policy only in 0 |
| Leave | Workforce operations | Types, holiday calendar, balances, request and manager approval | 1 planned |
| Time and attendance | Workforce operations | Source events/import, correction, approval and payroll inputs | 1 planned |
| Service requests | Employee services | Intake, assignment, comments/status and audit | 1 planned |
| Recruitment | Talent acquisition | Requisition, pipeline, interview scorecards, offers | 2 planned |
| Onboarding | Talent acquisition + workforce | Accepted offer conversion and multi-owner checklist | 2 planned |
| Performance | Talent development | Goals, review cycle, employee/manager feedback | 2 planned |
| Expenses | Employee services + payroll | Claim, receipt, policy approval and reimbursement export | 2 planned |
| HR analytics | Governed insights | Tenant/role-limited headcount, absence, hiring and payroll | 2 planned; dashboard in 0 is simple UI aggregates |
| Disciplinary | Restricted employee services | Need-to-know cases, evidence, review and retention | 2 planned |
| Exit | Workforce + employee services | Clearance, equipment/access, final-pay inputs | 2 planned |
| Learning and skills | Talent development | Catalog, assignments/completions, development and verified skills | 3 planned |
| Succession and talent | Talent development | Career paths, readiness, succession review/calibration | 3 planned |
| Compensation and benefits | Rewards | Bands, salary review budgets, benefits enrollment | 3 planned |
| Workforce planning | Insights + workforce | Scenario headcount, cost, actuals, contingent workforce | 4 planned |

SAP SuccessFactors and Workday are breadth references only. No enterprise feature parity is claimed. Cross-cutting dependencies: identity/scopes, effective dating, versioned workflows, document privacy, audit, notifications, tenant-safe reports and recovery.
